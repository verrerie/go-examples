1. Match the task to a tool

These are clues, not rules. Check the assumptions before you choose.

2. Check the operation cost

n = item count; h = tree height; V/E = graph vertices/edges. Constant-time map costs assume short keys.

Common costs in Go
StructureOperation and timeWatch for
SliceIndex O(1); append amortized O(1); insert/delete in the middle O(n).Growth can allocate and copy O(n) items.
StringByte index and substring slice O(1); concatenate O(n + m).Immutable. An index gives a byte, not a Unicode character. Slices may retain the original storage.
Linked listFind a node O(n); relink known adjacent nodes O(1).Singly linked deletion usually needs the previous node.
Map / setKey lookup, insert, delete: expected O(1). Scan values O(n).Hashing a long key costs time. A Go set can use map[T]struct{}.
Stack / queueStack push or queue append: amortized O(1); pop, front, peek O(1).Use a head index or ring buffer for a queue; do not shift all items.
BSTSearch, insert, delete O(h).Balanced: O(log n). A chain: O(n).
HeapPeek O(1); push/pop O(log n); build with heap.Init O(n).Only the root is guaranteed to be the minimum in a min-heap.
TraversalTree O(n); adjacency-list graph O(V + E).Assumes O(1) work per visit. Tree DFS space O(h); BFS O(width). Graph visited state O(V).
Search / sortBinary search O(log n); comparison sorting usually O(n log n).Include the cost of each check. Plain quicksort can take O(n²).

For a stable sort, equal keys keep their original order. Use it when that order matters.

4. Use a short interview checklist
  1. Introduce: give a brief, relevant background.
  2. Clarify: restate the task, constraints, and one example.
  3. Plan: explain the invariant and expected cost.
  4. Implement: name state clearly and explain key choices.
  5. Test: trace a small case, then boundaries and duplicates.
  6. Review: justify correctness, time, space, and trade-offs.
  7. Close: ask prepared questions about the work and team.

CHOOSE THE RIGHT TRAVERSAL

DFS or BFS?

DFS · finish a path

Use a stack for inorder, subtree results, or path state. A tree uses O(h) stack space.

BFS · finish a level

Use a queue for levels or shortest paths in an unweighted graph. A tree uses O(w) queue space.

For island counting, either works. In both cases, mark a cell when you discover it. h = tree height; w = maximum level width.
