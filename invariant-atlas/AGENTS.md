# Invariant Atlas style rules

- Use GitHub Dark as the default visual style for all pages and components.
- Use #0d1117 for the page, #161b22 for surfaces, and #30363d for borders.
- Use #e6edf3 for primary text, #9da7b3 for secondary text, and #58a6ff for links and focus accents.
- Use green primary actions, compact controls, system fonts, and clear spacing.
- Keep dialogs, inputs, code examples, and visual traces consistent with the dark theme.
- Write concise, direct technical English. Keep explanations easy to scan.
- Edit source files in src/ and rebuild with node build.mjs. Do not track generated dist/ files.
